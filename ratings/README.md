# Gatherer Community Card Ratings (version 1.0)

## ChangeLog:

- 1.0 (2026-06-10): First release.

## Description

This data set contains the per-printing **community ratings** for each card in
Gatherer. The original comment archive didn't include individual ratings by
user comment, so we can't see that fine-grained voting detail. But, an old MTG
Salvation [forum thread][extractor] dumped a bunch of Gatherer data to a CSV,
including per-printing average ratings.

## Data Organization:

The data is provided as a set of JSON files. Each one stores the ratings for
all rated printings in a given set. The files are keyed the same way as the
primary comment archive data: Organized by year, then by set, then by Gatherer
`multiverse_id` within the JSON file for each set. So, a rating file and its
comment file share the same relative path (e.g.
`ratings/199x/1993/1993-12-17 ARN.json` alongside
`data/199x/1993/1993-12-17 ARN.json`).

Here's an example:

```json
{
  "<multiverse id>: <card name>": {
    "rating": <community rating, 0–5, to 3 decimal places>
  }
}
```

## Notes:

- **Coverage:** 24,692 rated printings across 163 sets. Every printing the
  extractor records with a genuine rating is included — this is a superset of
  the sets in `data/`, since cards could be rated without ever being commented
  on.
- **Exclusion rule:** a printing is omitted (treated as unrated) when its
  extractor rating is blank, exactly `5.0`, or greater than `5.0`. A `5.0` is
  Gatherer's post-2014 placeholder for unrated cards — even the highest-rated
  real card (Underground Sea, Revised) tops out at `4.955`, so an exact `5.000`
  average is a sentinel, not a real value.
- **Set codes / dates:** filenames reuse the comment archive's set codes and
  release dates where a set already appears in `data/`; sets unique to the
  ratings use their Scryfall set code and release date.
